# Talks & Publications

## Talks

<div class="gy-pub" markdown>

**Embedded Linux Security Exercised on the Secure Platform GyroidOS**<br>
Michael Weiß, Johannes Wiesböck, Felix Wruck, Maximilian Peisl, Fraunhofer AISEC<br>
Class 2.4 at the embedded world Conference 2026, March 11, 2026, Nuremberg, Germany.
The class shows how Linux can be used on embedded devices to comply with
security-related certification requirements like IEC 62443 or Common Criteria —
focusing on kernel mechanisms that protect the integrity of code and data, with
practical insights based on GyroidOS.

[:octicons-arrow-right-24: Conference program (PDF)](https://cdn.componeers.net/wes/embedded%20world%20Conference%202026_program.pdf)

</div>

<div class="gy-pub" markdown>

**Secure System-on-Chip: Protecting Operating Systems and Hardware**<br>
Interview with Dr. Michael Weiß, Fraunhofer AISEC<br>
Published by FMD.insight (Research Fab Microelectronics Germany), December 15, 2025.
The interview covers hardware-anchored platform security with GyroidOS — container
isolation, TPM and OpenTitan trust anchors, RISC-V, and secure system-on-chip
development for IoT and 6G.

[:octicons-arrow-right-24: Interview (English)](https://www.cybersecurity.blog.aisec.fraunhofer.de/en/secure-system-on-chip-protecting-operating-systems-and-hardware/)
&nbsp;
[:octicons-arrow-right-24: Interview (German)](https://fmd-insight.de/de/news/interviews/secure-system-on-chip-ueber-den-schutz-von-betriebssystemen-und-hardware/)

</div>

<div class="gy-pub" markdown>

**Embedded Linux security exemplified on the secure platform GyroidOS**<br>
Felix Wruck, Fraunhofer AISEC<br>
Security session at the OSADL Networking Day 2025, June 26, 2025, Heidelberg, Germany.

[:octicons-arrow-right-24: Event page](https://www.osadl.org/OSADL-Networking-Day-2025.networking-day-2025+M580c41ce1eb.0.html)

</div>

<div class="gy-pub" markdown>

**Embedded Linux Security**<br>
Michael Weiß, Johannes Wiesböck, Felix Wruck, Maximilian Peisl, Fraunhofer AISEC<br>
Class 3.3 at the embedded world Conference 2025, March 11, 2025, Nuremberg, Germany.
Hands-on class including Raspberry Pi exercises on secure boot, kernel integrity
